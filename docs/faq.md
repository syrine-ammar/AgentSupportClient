# FAQ Générale - TechMarket

## Paiement
**Quels moyens de paiement sont acceptés ?**
Carte bancaire (Visa, Mastercard), PayPal, et paiement en 3 fois sans frais pour les commandes supérieures à 100€.

**Pourquoi ai-je été débité deux fois pour la même commande ?**
Cela peut être une autorisation bancaire temporaire qui s'affiche en double mais qui sera automatiquement annulée sous 3 à 5 jours. Si le double débit persiste après 5 jours, contactez le support avec une capture de votre relevé bancaire.

## Compte client
**Comment modifier mon adresse de livraison après une commande ?**
Tant que la commande n'est pas expédiée (statut "processing"), l'adresse peut être modifiée depuis l'espace client ou via le support.

**Comment supprimer mon compte ?**
Une demande de suppression de compte peut être faite depuis les paramètres du compte. Le traitement prend jusqu'à 30 jours conformément au RGPD.

## Produits
**Les produits sont-ils neufs ou reconditionnés ?**
Sauf indication contraire explicite sur la fiche produit ("reconditionné"), tous les produits vendus par TechMarket sont neufs et scellés.

**Le SmartHome Router X3 est-il compatible avec la fibre optique ?**
Oui, le SmartHome Router X3 est compatible avec toutes les box fibre standards via un câble Ethernet WAN.

## Programme de fidélité
- Bronze : 0-499€ d'achats cumulés.
- Silver : 500-1499€ d'achats cumulés, livraison à -50% de frais.
- Gold : 1500€+ d'achats cumulés, livraison gratuite illimitée + support prioritaire.
